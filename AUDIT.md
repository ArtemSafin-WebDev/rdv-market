# Проверка ТЗ RDV Маркет

Дата: 4 октября 2026. Источник: [Google Docs — техническое задание](https://docs.google.com/document/d/1KBORlwQXju2VSY33jP1MWrPpVyHzgFiJGdUDSkytQg4/edit). Проверена локальная версия на localhost:4173, исходный код и сборка.

## Итог

Фронтенд-возможности пяти блоков реализованы. Обнаруженные при проверке привязки к исходной графике устранены. Текст находится в потоке и увеличивает высоту блоков; число строк не ограничивается. Шахматка учитывает высоту обоих состояний, поэтому длинные результаты не обрезаются и не меняют размер карточки при наведении.

Это проверка локальной верстки, а не завершенной интеграции с Битриксом. Регистрация блоков, формы настроек, сохранение контента и загрузка файлов через админку отсутствуют. Соответствие реализации внутренним механизмам RDV-IT без его исходников и админки не подтверждено.

## Что изменено по результатам проверки

1. Удалены отрицательные отступы изображений в зависимости от номера карточки.
2. Убрана фиксированная высота контейнера картинки под текстом видео. Постер и обычная картинка также сохраняют пропорции.
3. Иконки используют ограниченное место и object-fit: contain.
4. Текст шахматки, результаты, надпись «В результате» и «Подробнее» выведены из абсолютного позиционирования. Ряды сетки растут по содержимому; оба состояния наложены через grid и участвуют в расчете размера.
5. Декоративные композиции подключены самостоятельными WebP в 2×, иллюстрации первого экрана — WebP из экспорта Figma 4×. CSS компонентов не содержит координат отдельных картинок исходного дизайна. Фоны вкладок не наследуют размеры и смещения старых изображений.
6. Добавлен перенос длинных слов. У текста нет line-clamp, фиксированной высоты или скрывающего overflow.

Фоны по своей природе используют cover и могут обрезаться по краям при смене пропорций. Контентные изображения карточек и видеоблока не обрезаются. Для фонов нужно подбирать графику, сохраняющую читаемость текста.

## Проверка

- 41 браузерная проверка: 2/3/4 карточки, 3/4 показателя, центрирование кнопок, переключение вкладок, колесо, два режима hover, текст/список, скрытие элементов, ширины 1280 и 1600.
- Тексты примерно по 1800 символов в каждом описании, длинные заголовки и строки без пробелов. В тесте нет выхода текста за границы и абсолютного позиционирования текстовых элементов; hover не меняет высоту карточки.
- Иллюстрации 292×300, 1200×180 и 180×600; дополнительно портретный постер 180×600. Проверены пропорции, отсутствие пересечений, размер иконок, общие правила фона.
- Тестовый локальный WebM: readyState 4, воспроизведение началось, error = null. Rutube: создание iframe, закрытие и возврат фокуса. Просмотр ролика целиком не проверялся.
- npm run build проходит.

Результаты: [основная проверка](output/playwright/content-qa-results.txt), [плеер](output/playwright/video-qa-results.txt), [постер](output/playwright/poster-qa-results.txt), [вид страницы](output/playwright/content-independent-desktop.png).

## Дополнительная проверка после замечаний

Состояния шахматки и вкладок сверены с разделом Figma `957:2724`. Шапка и футер взяты из HTML действующего сайта. Размер кнопки футера при ширине 1600 px совпадает с продакшеном: 230×46 px, шрифт 12 px, внутренние отступы 16×30 px.

Общая обертка удалена. Пять секций и заголовок имеют собственные БЭМ-классы; правила CSS ограничены ими. Два экземпляра табов и видео проверены независимо, включая повторную инициализацию. Параметры видео хранятся в секции. Проверка влияния CSS на 333 элемента заимствованных шапки и футера: различий в проверенных свойствах нет. Подробности: `output/playwright/bem-qa-results.txt`.

Ранее указанные 41 сценарий проверяли прежние имена классов; после изменения имен проведена дополнительная проверка независимых экземпляров и длинного контента, а не повтор всех прежних сценариев.
