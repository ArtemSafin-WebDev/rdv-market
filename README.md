# RDV Маркет

Адаптивная верстка на HTML, CSS и JavaScript. Нужен Node.js 18+.

```sh
npm run dev
```

Локальный адрес: http://localhost:4173.

```sh
npm run build
npm run preview
```

Сборка — в `dist/`, отдельные блоки — в `dist/blocks/`.
Контент и настройки — в `scripts/config.js`, стили — в `styles/blocks.css`.

Расстояние между секциями задаётся через `margin-bottom` предыдущей секции, с отдельными значениями для десктопа, планшета и мобильного. Паддинги используются для внутренних отступов и композиции фоновых блоков. У вложенного блока статистики внешние отступы обнулены: расстояние до следующей секции задаёт блок архитектуры.

Графика над заголовком — один SVG, экспортированный из Figma: `assets/figma/hero-brand.svg`. Для замены достаточно заменить этот файл или задать другой путь в `hero.image`; подпись для доступности — в `hero.imageAlt`. `hero.image: null` скрывает изображение.

В `hero.cards` можно задать от 1 до 4 карточек. На десктопе они сохраняют ширину четверти ряда и центрируются, если карточек меньше четырёх. На планшете — до двух карточек в ряду с центрированием последней, на мобильном — одна. `hero.showCards: false` скрывает весь ряд.

Фон первого блока выводится через `<picture>` и `<img>`: `hero.background` задаёт десктопное изображение, `hero.backgroundMobile` — мобильное (до 767 px). На мобильном фон ограничен заголовком и кнопками; карточки расположены ниже на белом фоне.

В `chess.cards` детальная информация для ховера задаётся в `results`. CSS через `:has()` проверяет наличие метрик в разметке: если их нет, при наведении и фокусе перекрашивается только кнопка со стрелкой. `hover: 'simple'` включает такое поведение даже при наличии данных; `hover: 'results'` показывает заполненный блок результатов.
